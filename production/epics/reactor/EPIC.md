## Goal

> 你从几样基础物质开始定规则，把规则封成部件、把部件封成工厂，一层层往上调用 ——
> 直到一捧基础物质长成一台你没设计过的完整系统。

## Scope

MVP 共 7 项（`design/game-brief.md`）：

1. 一个 2D 空间 + 3–5 种基础物质（含两两反应表）
2. 规则编辑：条件 + 效果，能加 / 删 / 改 / 调参
3. 规则组合：一条规则能修饰、触发、嵌套另一条规则
4. 反应结算循环 + 最小可视化反馈：看得见反应在发生，也看得见是哪条规则干的
5. **部件 / 工厂：封装** —— 跑通的组合变成一个世界里可见、可被再次调用的实体 ← *全游戏成不成立就看这一步*
6. 目标条件层（可插拔）：谜题 / 生存 / 沙盒 = 三个条件挂在同一引擎上
7. 存档重跑
